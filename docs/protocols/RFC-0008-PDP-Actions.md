# 🎬 RFC-0008 — PDP ACTIONS & INTERVENTIONS SPECIFICATION
**Category**: Standards Track  
**Protocol Version**: 1.0  

---

## 1. ACTION COMMAND MODEL

PDP Actions represent executable commands dispatched by the **Action Cortex** to edge hardware nodes:

- `action.audio.play_calming` (432 Hz soundscapes)
- `action.audio.play_voice` (Recorded owner voice clip)
- `action.feeder.dispense` (Precision portion control)
- `action.camera.snapshot` (Low-latency high-res frame capture)
