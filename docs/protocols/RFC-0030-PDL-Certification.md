## 1. "PDL CERTIFIED" MANUFACTURER PROGRAM

To earn the **"PDL Certified"** badge, third-party pet hardware manufacturers must submit their hardware descriptors to automated validation against the Project One PDL JSON Schema Repository.

### Certification Test Criteria:
1. Valid JSON/CBOR schema syntax.
2. Accurate unit declarations (`bpm`, `ml`, `g`, `celsius`).
3. Successful execution of declared event manifests during synthetic test harness evaluation.
