## 1. CERTIFICATION LEVELS ("WORKS WITH PROJECT ONE")

Project One defines three certification tiers for third-party hardware manufacturers:

| Certification Level | Requirements | Features Granted |
| :--- | :--- | :--- |
| **Level 1 (Basic Compatible)** | PDP 1.0 Telemetry JSON format compliance | Basic event logging in Device Hub |
| **Level 2 (Certified Sensor)** | mTLS 1.3 authentication + PDL schema validation | Full AI Brain integration & story timeline |
| **Level 3 (Pro Guardian)** | Hardware Enclave + Local TPU Edge Inference + Canary OTA | Autonomous intervention trigger access |

---

## 2. CERTIFICATION COMPLIANCE TEST SUITE

Third-party devices must pass automated compliance testing covering:
1. Pairing in $< 120\text{s}$.
2. Sub-$150\text{ms}$ event dispatch.
3. Cryptographic replay rejection test.
4. Seamless OTA rollback verification.
