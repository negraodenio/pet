# 🔌 PO-0005 — PET DEVICE PROTOCOL (PDP 1.0)

> **Document ID**: PO-0005  
> **Category**: Protocols  
> **Status**: Protocol Standard Specification  

---

## 1. OBJECTIVE

PDP 1.0 (Pet Device Protocol) is the open, universal wire protocol connecting all pet hardware devices (Vision Devices, Smart Beds, Collars, Feeders, Scales) to the AI Brain.

---

## 2. TRANSPORT & MESSAGE STRUCTURE

- **Transport**: WebSockets (Real-time events), MQTT (Low-power sensor telemetry), WebRTC (Low-latency audio/video).
- **Message Payload**:

```json
{
  "pdp_version": "1.0",
  "device_id": "cam_8f42",
  "device_type": "camera",
  "timestamp": 1785835578000,
  "payload": {
    "event": "eating",
    "confidence": 0.98,
    "bbox": [120, 240, 450, 680],
    "pet_id": "pet_lola"
  }
}
```
